# Chrome Web Store Listing Draft

## Extension Name

Overleaf LaTeX Formatter

## Short Description

Format the active LaTeX file in Overleaf with one click or shortcut.

## Detailed Description

Overleaf LaTeX Formatter is a lightweight Chrome extension that formats the full LaTeX document in your active Overleaf editor.

### Key features

- One-click format from toolbar icon
- In-page `Format` button on Overleaf
- Keyboard shortcut support (`Command+Shift+U` on macOS)
- Local-only processing in browser (no remote formatting service)
- Basic indentation for environments and conditional blocks
- Preserves content inside code/verbatim-like environments (`verbatim`, `Verbatim`, `lstlisting`, `minted`)

### Typical usage

1. Open your Overleaf project
2. Click the extension icon, click the in-page `Format` button, or use the keyboard shortcut
3. The extension formats the entire current file and displays a status toast

### Notes

- Formatting is rule-based and designed for common LaTeX structures
- Complex custom macro styles may require manual adjustment
