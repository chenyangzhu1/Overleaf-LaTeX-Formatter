# Privacy Policy

Last updated: March 6, 2026

## Overview

Overleaf LaTeX Formatter is a Chrome extension that formats LaTeX source files inside Overleaf editors.

## Data Collection and Use

This extension does **not** collect, store, sell, or share personal data.

- No account registration
- No analytics SDK
- No tracking pixels
- No external telemetry

## Data Processing

The extension processes text locally in your browser to format LaTeX code.

- Processing happens in-browser only
- No document content is sent to remote servers by this extension

## Network Access

The extension is scoped to Overleaf domains (`https://www.overleaf.com/*` and `https://*.overleaf.com/*`) so it can access editor content for formatting.

The extension itself does not make remote API calls for formatting.

## Permissions

- `host_permissions` for Overleaf domains: required to run content scripts where formatting is requested

## Changes to This Policy

If this policy changes, updates will be posted in this repository and reflected by the "Last updated" date above.
