# Overleaf LaTeX Formatter

[English](README.md) | 中文

## 作用

这是一个用于 Overleaf 的 Chrome 插件，可以一键格式化当前编辑器中的 LaTeX 文件。

## 用法

1. 打开 Overleaf 项目并进入 LaTeX 编辑页面。
2. 使用以下任一方式触发格式化：
   - 点击 Chrome 工具栏中的插件图标
   - 点击 Overleaf 页面上的悬浮按钮
3. 插件会对当前编辑器中的全文进行格式化。
