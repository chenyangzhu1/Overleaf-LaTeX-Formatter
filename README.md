# Overleaf LaTeX Formatter

English | [中文](README_zh.md)

## What It Does

Overleaf LaTeX Formatter is a Chrome extension for Overleaf. It formats the current LaTeX file in the active editor with one click.

## How To Use

1. Open an Overleaf project and enter a LaTeX editor page.
2. Trigger formatting in one of these ways:
   - Click the extension icon in Chrome
   - Click the floating button on the Overleaf page
3. The extension formats the full content of the current editor.
